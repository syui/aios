# いくつもの CPU でいっしょに動いたときの速さ

aish の `bench` (kind smp、linux、record) が作る。もとは bench/smp.jsonl (1 行 1 回の記録)。測るのは test/smpbench.c で、aios と
Linux の VM で同じプログラム (同じ libc) を動かす。op ごとに、1 つのプロセスでまわしたものと、CPU の数 (P) だけのプロセスが
いっしょにまわしたもの (それぞれ自分のファイル、パイプ、ソケットを使う)。伸びは 1 つのときの何倍まわせたか (P なら CPU の数だけ
伸びた、1 なら 1 つずつしか動けていない)。時間の比は P のときの aios / Linux (1 より小さければ aios が速い)。BKL は P のときの
/proc/ai/bkl: 大きなロックを待った時間 (100% は CPU 1 つぶん) と、長く持ったシステムコール (どこからロックを分けるか)。
VM は QEMU の TCG (x86 の上で aarch64 をまねる) で、CPU はホストのスレッドなので、ホストがいそがしいと伸びが小さくなる
